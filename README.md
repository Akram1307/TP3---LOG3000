# Calculatrice Flask – LOG3000 TP3

**Équipe :** 21

## Objectif
Application web de calculatrice simple construite avec Flask (Python).
L'utilisateur saisit une expression à un opérateur (+, -, *, /) et le
serveur calcule le résultat.

## Prérequis
- Python 3.8+
- pip
- Git

## Installation
1. Cloner le dépôt :
   ```bash
   git clone https://github.com/Akram1307/TP3---LOG3000.git
   cd TP3---LOG3000
   ```
2. Installer Flask :
   ```bash
   pip install flask
   ```
3. Lancer l'application :
   ```bash
   python app.py
   ```
4. Ouvrir http://127.0.0.1:5000 dans un navigateur.
